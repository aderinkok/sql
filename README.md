### Veritabanı Betikleri

`veritabani` klasöründeki betikler SQL Server Management Studio'da açılıp F5 ile çalıştırıldığında ilgili veritabanını tabloları ve verileri ile birlikte oluşturur. Betik tekrar çalıştırılırsa veritabanı silinip ilk haline döndürülür.

| Betik                 | Veritabanı                                   | Çalışma Soruları                                                                   |
|-----------------------|----------------------------------------------|------------------------------------------------------------------------------------|
| Kampus.sql            | Kampus (öğrenci işleri + kütüphane, 11 tablo) | calisma_sorulari_select_1, calisma_sorulari_insert_update_delete, calisma_sorulari_4_JOIN |
| Northwind_Script.sql  | Northwind                                    | calisma_sorulari_select_2, ders_uygulama/hafta3                                    |
| Ornek.sql             | Ornek (tek tablo)                            | -                                                                                  |
| db_okul.sql           | Db_okul                                      | -                                                                                  |

`calisma_sorulari_3` kendi `final` veritabanını sorular içinde oluşturur.

### Konu Sırası ve Çalışma Soruları

Çalışma soruları derste işlenen konu sırasına göre düzenlenmiştir. Her bölümde yalnızca o bölüme kadar işlenen konular kullanılır.

| Dönem        | Konu                                                                                                     | Çalışma Soruları                                              |
|--------------|----------------------------------------------------------------------------------------------------------|---------------------------------------------------------------|
| Vize öncesi  | 1- SELECT                                                                                                | calisma_sorulari_select_1 (1. bölüm), calisma_sorulari_select_2 (1. bölüm) |
| Vize öncesi  | 2- ORDER BY                                                                                              | calisma_sorulari_select_1 (2. bölüm), calisma_sorulari_select_2 (2. bölüm) |
| Vize öncesi  | 3- DISTINCT, TOP                                                                                         | calisma_sorulari_select_1 (3. bölüm), calisma_sorulari_select_2 (3. bölüm) |
| Vize öncesi  | 4- WHERE, AND, OR, LIKE                                                                                  | calisma_sorulari_select_1 (4. bölüm), calisma_sorulari_select_2 (4. bölüm) |
| Vize öncesi  | 5- Takma ad, toplama fonksiyonları, GROUP BY, HAVING, BETWEEN, IN, NOT, NULL, sütun birleştirme, yorum satırı | calisma_sorulari_select_1 (5. bölüm), calisma_sorulari_select_2 (5. bölüm) |
| Ek           | Fonksiyonlar, şifreli veriler                                                                            | calisma_sorulari_select_1 (6. bölüm)                          |
| Vize sonrası | JOIN                                                                                                     | calisma_sorulari_4_JOIN, calisma_sorulari_select_2 (6. bölüm) |
| Vize sonrası | INSERT, UPDATE, DELETE                                                                                   | calisma_sorulari_insert_update_delete                         |
| Vize sonrası | CREATE, ALTER, DROP (genel tekrar)                                                                       | calisma_sorulari_3                                            |
